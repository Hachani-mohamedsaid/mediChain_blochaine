# Flux réel (sans démo)

1. Inscrire un **patient** et un **médecin** via `/register`
2. Patient : upload d’un dossier (`/records`)
3. Patient : grant vers le médecin (`/access`)
4. Médecin : consulter (`/records` → Consulter)
5. Patient : révoquer
6. Vérifier l’historique (`/audit`) et le contrat (`/blockchain`)
